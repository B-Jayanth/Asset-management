# ZylloTech Asset Management System

## About the Project

ZylloTech Asset Management is a web-based IT Asset Management System designed to help organizations manage, monitor and maintain their IT assets efficiently.

The application supports three organizations (C1, C2 and C3) through a centralized dashboard. Administrators can manage employees, track assigned assets, monitor available inventory, handle asset requests and manage asset returns.

The system provides a professional dashboard with interactive graphs, company-wise analytics and inventory reports, making asset management easier and more organized.

## Features

### 1. Dashboard
- View the overall asset inventory across all three companies.
- Compare C1, C2 and C3 using a combined graph.
- View separate analytics for each company.
- Monitor assigned, available, damaged and maintenance assets.
- View employee statistics and inventory values.
- Interactive charts with selectable data categories.

### 2. Company Management
- Manage three organizations: C1, C2 and C3.
- Edit company names.
- Upload, replace or remove company logos.
- View individual company information.
- Access company-specific employee records.

### 3. Employee Management
- Add, view and edit employee information.
- Maintain employee ID, name, email, department and contact details.
- Assign employees to their respective organizations.
- Filter employees based on organization.
- View assets assigned to individual employees.

### 4. Asset Management
- Add and manage IT assets.
- Maintain asset details such as category, brand, model and serial number.
- Track laptops, desktops, monitors, keyboards, headsets and other equipment.
- Monitor asset availability and condition.
- Update inventory quantities.

### 5. Asset Assignment
- Assign available assets to employees.
- View assignment details.
- Transfer assets between employees.
- Maintain assignment history.

### 6. Asset Requests
- View employee asset requests.
- Accept or reject requests.
- Prepare optional email responses for employees.
- Track request status.

### 7. Asset Returns
- Request asset returns from employees.
- View and manage return requests.
- Update return status.
- Maintain asset return records.

### 8. Inventory Management
- View total asset quantities.
- Monitor assigned and available stock.
- Add new inventory.
- Remove available inventory.
- Track inventory by asset category.

### 9. Reports and Analytics
- Generate asset management reports.
- Download reports in PDF and CSV formats.
- Review company-wise inventory information.
- Monitor asset allocation and availability.

### 10. Settings and Profile
- Manage organization details.
- Configure asset ID prefixes.
- View workspace information.
- Manage company profiles.
- View logged-in user information.
